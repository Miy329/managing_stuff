< 구매 물품 관리 서비스 >

1\. 프로젝트 개요



이 프로젝트는 사용자가 구매한 물품의 정보를 기록하고 관리할 수 있도록 만든 웹 서비스입니다.

물품의 AS 기간, 구매처, 보관 위치, 메모 등을 함께 저장하여, 시간이 지나도 필요한 정보를 쉽게 확인할 수 있도록 하는 것을 목표로 합니다.

전자기기나 중요 물품을 중심으로 개인이 사용하는 물품 관리용 서비스입니다.



2\. 주요 기능

ㄴ1) 회원가입 및 로그인



회원가입 기능 제공

아이디, 이름, 비밀번호, 성별, 전화번호 입력

비밀번호는 암호화하여 데이터베이스에 저장

로그인 기능

등록된 회원만 서비스 이용 가능

세션을 이용하여 로그인 상태 유지

로그아웃 기능 제공



ㄴ2) 메인 화면 (물품 관리)



로그인한 사용자가 등록한 물품 목록 출력

물품 사진과 이름을 함께 보여주는 목록 화면

본인이 등록한 물품만 조회 가능

회원정보 수정 기능 제공

이름, 전화번호 수정

비밀번호는 입력한 경우에만 변경



ㄴ3) 물품 등록 및 수정

물품 등록 기능

물건 사진 업로드

물품명 입력

물품 등록 날짜--> 데이터베이스에서 자동으로 입력됨

AS 기간, 구매처, 보관 위치 입력

구매일 선택

메모 입력 가능

물품 수정 기능

기존에 저장된 정보가 폼에 자동으로 출력됨

수정 후 데이터베이스에 반영



3\. 개발 환경

PHP 8.x

MySQL (MariaDB)

Apache (XAMPP 환경)

HTML, CSS

phpMyAdmin



4\. 

XAMPP 실행 후 Apache, MySQL 서버 시작

phpMyAdmin에서 데이터베이스 project01\_db 생성

제공된 SQL 파일을 실행하여 member, items 테이블 생성

프로젝트 폴더를 htdocs 디렉토리 아래에 위치

이미지 업로드를 위한 uploads 폴더 생성

브라우저에서 아래 주소로 접속

http://localhost/project/login.php-> 시작화면

회원가입 후 로그인하여 기능 확인



5\. 데이터베이스 구성

member 테이블: 회원 정보 저장

items 테이블: 물품 정보 저장

회원과 물품은 외래키로 연결되어 있으며, 회원 삭제 시 해당 회원의 물품도 함께 삭제됨



6\. 소스 코드 

로그인: login.php, login\_process.php

로그아웃: out.php, logout.php (main.php에서 이동함)

회원가입 등록: registForm.php, regist\_process.php

회원정보 수정: editMember.php, editMember\_process.php

메인(로그인 후 볼 수 있는 화면): main.php

물건 등록하기: add\_item.php, add\_item\_process.php

등록된 물건 수정: editItem.php, editItem\_process.php



\+비밀번호 암호화하는 파일 : make\_hash.php
